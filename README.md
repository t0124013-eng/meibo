# 説明会 名簿同期ツール

説明会の予約者名簿Excelを、申込管理システムから出力した申込データと突き合わせて更新するブラウザアプリです。
`index.html` 1ファイルだけで動きます。画面上部のタブで **中学説明会 / 高校説明会** を切り替えます（タブごとにファイルを別々に保持）。

## できること

1. 名簿の各シート（AM・PM・個別のみ など）と申込データ（Sheet0）を「氏名＋ふりがな」で照合
2. 申込データにいない人 → 「キャンセル」シートの末尾へ移動し、元のシートから削除
3. 名簿にいない人 → 空欄の予約行（№のみの行）へ申込順に追加（足りなければ末尾に№を続けて追加）
4. 追加した人のうち、参加者マスタに同じ氏名がない人だけ「新規」欄に 1
5. 合計行・集計式の参照範囲を行数に合わせて修正
6. フリガナ順シート（濁点・半濁点を無視した50音順、同じ読みは 清音→濁点→半濁点）を作成
7. フリガナ順を「名簿完成形」シートと同じ表示形式（50音見出し・出欠列つき）にしたシートを作成
   - 名簿Excelに「名簿完成形」シートがあればその書式、なければ内蔵の同じ書式（A3縦・横1ページ）で作成

## 中学と高校の違い（自動で吸収）

| | 中学 | 高校 |
|---|---|---|
| 読みの見出し | ふりがな | フリガナ |
| 学校 | 在籍小学校 | 在籍中学校 |
| その他の列 | 都道府県・市区町村・参加予定人数 | 希望コース・指名 |
| 学年 | 小学６年生 → 6 | 中学3年生 → 3 |
| 名簿完成形シート | 名簿内のシートを使用 | 内蔵の書式を使用 |

列は見出し名で対応づけるので、列の並びが変わっても動きます。タブと違う種類のファイル（例：高校タブに中学の名簿）を入れると警告が出ます。

## 使い方

1. ページを開き、次のExcelをまとめてドロップ（役割は自動判別）
   - 名簿（`AM` / `個別のみ` / `キャンセル` / `名簿完成形` などのシートを持つファイル）
   - 申込データ（`Sheet0`、1つまたは複数）
   - 参加者マスタ（`参加者マスタ` シート）
2. 申込データごとの「反映先シート」を確認（ファイル名やイベント名から自動で選ばれます）
3. 「名簿を更新する」→ 結果と検証チェックを確認 → ダウンロード

## 個人情報について

- Excelの読み込み・処理・書き出しはすべてブラウザの中で行われ、ファイルはどこにも送信されません。
- 外部から読み込むのは Excel処理ライブラリ（ExcelJS 4.4.0 / cdnjs）とフォント（Google Fonts）だけです。
- **生徒の名簿Excelはリポジトリに置かないでください。** `.gitignore` で `.xlsx` を除外しています。

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリにpush
2. GitHub の Settings → Pages → Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で使えます
